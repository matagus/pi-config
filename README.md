# Pi Configuration

My personal configuration for [pi](https://pi.dev/) — the AI coding agent.

## Packages

This setup includes extensions for:
- LiteLLM provider integration
- Web access and search
- Code review and safety tools
- Memory management
- Excalidraw diagrams
- An orchestrator skill that launches specialized subagents to implement complex tasks.
- A set of subagents for specific tasks using https://github.com/tintinweb/pi-subagents
- Artifacts
